# 成长与扩展

所有管理入口在本机页面侧栏“成长与扩展”，沿用原工作台的令牌认证和样式。新增私人配置留在 `data/`；模型、账号缓存、导入素材留在 `.runtime/`，不发布到 Git。

## 记忆与话题

使用本地 384 维多语言 ONNX 向量检索，模型首次下载约 135 MB，位于 `.runtime/models/embeddings`。可点击“准备本地语义模型”；已缓存的模型随服务启动在后台载入。无需付费 embedding API。

索引包含事实、偏好、最近 3000 条聊天和已保存浏览经历；一次语义查询检索至多 5000 条索引。来源和日期随条目保存。旧事实的日期表示索引导入时间，不能当作最初说话日期。模型不可用时返回明确的 `keyword-fallback`。

“纠错”更新条目并重建聊天上下文；“遗忘”清空本条索引和向量缓存，同时移除对应聊天/经历原文或事实偏好，并重建会话。其他条目、旧摘要、日记和历史备份需要在各自页面检查，避免同一事实的其他副本继续保留。向量缓存不进入备份，恢复后可重建。

共同话题保留延续点与来源ID。完成的非开发任务会形成话题；模型也可按真实共同经历保存。停用或移除话题后不再注入后续交流。主动聊天仍遵守已有时段、闲置、每日次数与额度保护。

## 灵活定时

- 每日：北京时间的 HH:mm。
- 每周：一个或多个星期；0 是周日，1 是周一，6 是周六。
- 间隔：从保存时刻起按固定分钟数计算。
- 一次性：指定带时区的未来时间；执行后不重复。

QQ 可直接说“每周五晚上九点找两部电影推荐给我”“两小时后提醒我休息”“把刚才那个任务改成九点”。模型使用真实保存工具，修改前先列出已有任务ID。原有 `/每日任务` 和每日指令继续可用，列表显示下一次执行时间。

提醒原文与 AIHOT 新闻无需模型生成；网页/安卓/游戏任务进入原任务池。电脑和服务需运行、QQ需在线；错过超过五分钟会记录跳过，重启不补跑旧任务。

## 技能与 MCP

内置模块可独立启停。网页和安卓停用会停止对应活动；语音停用打断语音；Minecraft停用会断开服务器；定时停用停止领取新一轮安排。已停用模块的模型工具也会被后端拒绝。

技能工作流将名字、具体目标、通道和时长保存为可编辑模块；每次更新增加版本号，可运行或删除。内置程序模块随仓库升级更新，不安装任意第三方可执行插件。

MCP支持 Streamable HTTP。保存服务地址、令牌和允许调用的工具名后可查询真实工具列表，按需调整允许名单。令牌只保存在私人配置，状态接口仅返回“已配置”。模型不能安装服务或扩大允许名单。远端 HTTP 地址需使用 HTTPS，本机可用 HTTP。

## 任务、登录和收藏

“进度与收藏”展示真实最后工具动作、摘要、挂起原因、下一步处理提示和已保存截图。运行或挂起任务的已有截图自动刷新。QQ询问进度时使用真实任务状态工具。

平台诊断分别记录最近请求成功、需要人工验证、会话失效、未获取正文、请求超时和未知请求失败。CLI超时不会自动归类为登录失效。打开对应平台后由管理员完成登录/验证。

网络与登录错误会挂起并保留进度。时限内可以继续；过期、失败或重启停止的任务通过“从检查点继续”新建时限，将原目标、进展及中断原因传给新任务，先观察当前页面。不会自动重复旧动作。收藏保存原文链接、摘要和感想，可以打开或移除。

## 实时语音

点击“开启麦克风”后由浏览器请求麦克风权限。音频在本地编码，Whisper在本机识别；对话文本仍使用当前Codex模型和既有额度保护。检测到约850毫秒静音时提交本句，单句最长30秒。

只将最终回答文字流送给分句语音合成，不朗读思考或过程评论。Kokoro在本机逐句生成音频；可在回答生成过程中开始播放，真实首句延迟取决于模型与电脑性能。说话或点击“打断回复”会停止播放并中断语音回合。建议戴耳机，避免扬声器回声误触发。也可输入文字测试流式回复。

服务端单测验证分句合成先于模型完成、监听清理和评论过滤；已验证浏览器文字→模型→Kokoro播放，以及本地Kokoro→Whisper。真实麦克风、嘈杂环境、回声和长时间打断体验需由使用者现场验证。

## 形象小窗与 Live2D

内置SVG形象可眨眼、摆动、显示真实活动状态，并接收同源语音页的口型幅度。通过按钮打开独立浏览器小窗；它是浏览器小窗，不是原生置顶透明桌宠进程。

Live2D支持 Cubism 3/4 `*.model3.json`，使用MIT许可的 Pixi Live2D Display 0.4.0 浏览器渲染文件与PixiJS。导入有授权的模型ZIP，再自行提供官方 `live2dcubismcore.min.js`。ZIP中的模型资源写入 `.runtime/avatar/<随机目录>`，拒绝目录穿越和无关脚本；Core单独导入。界面显示导入的模型路径，填入并保存后重开小窗。

仓库不包含Cubism Core或角色模型。当前已验证内置形象和素材导入校验；外部Live2D的动画、物理与口型须用实际模型继续验收。VRM尚未接入。

## Minecraft

需要 **Java版**服务器。填写地址、端口、机器人名字和版本（留空可检测）；离线账号仅适用于服务器允许的情形，正版服务器用Microsoft设备登录。登录材料在 `.runtime/minecraft-auth`，不进入公开Git。

连接后可以用管理页或QQ要求：

- 跟随可见玩家，本地持续更新路径；可继续与coco聊天。
- 单次移动到128格内的坐标，单次动作45秒上限。
- 采集32格内指定方块，单次1–16块，尝试靠近掉落物。
- 将背包物品整理到六格内的箱子/木桶；可指定物品。
- 在六格内有支撑的空位置放置一块背包方块，多次执行可逐步搭建。

动作使用Mineflayer与pathfinder，不依赖截图逐帧控制。Minecraft为单机器人独立会话，动作一次一项，停止、暂停和额度保护会停止本地控制。尚不包含复杂蓝图规划、容器分类规则或PVP快速反应。

已用本机临时Minecraft协议服务器验证真实登录、状态读取和停止；尚未连接使用者的真实世界验证跟随、采集与建造。请先用测试世界体验。
